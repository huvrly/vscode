# Huvrly (built-in)

This is a **built-in** extension for the Huvrly VS Code fork.

## Features

- Adds a **Huvrly** Activity Bar container
- Shows **Agent Status** view
- Pings the local Platform API `GET /agent/status`

## Settings

- `huvrly.agent.baseUrl` (default: `http://localhost:3001`)

## Notes

This extension is intended to stay small and stable. Prefer adding capabilities to the Platform Agent API.
